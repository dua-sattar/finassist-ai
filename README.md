# FinAssist AI

> **Portfolio Demonstration — Synthetic Data Only — Human Review Required**

FinAssist AI is a portfolio project showcasing an AI-powered financial operations
agent for a fictional financial advisory company. It combines a LangGraph agent,
a RAG knowledge base, synthetic document analysis, and a mock CRM behind a
Streamlit dashboard.

This project uses **entirely synthetic, fictional data**. It is not a production
financial system, is not affiliated with any real financial institution, and does
not provide real financial advice.
